# v4.0.0：小丑爆脑与舞王队形完善

本版新增玩法限定于「我是僵尸」模式 61–70，包括无尽。整合此前 v3.0.4 的全部修复。

## 小丑与随机血量

- 小丑的提前爆炸概率由 `Rand(20)==0`（5%）提高为 `Rand(5)==0`（20%）。仍使用原来的三分之一行走距离引信和开盒倒计时，不会刚出现就直接爆炸。新概率在初始化时抽取，已生成的小丑保留已有倒计时。
- 小丑实际爆炸时，先执行原来的植物伤害／剩余阳光结算，再用相同的半径 90 圆形碰撞函数检测五行脑子。脑子矩形取本版资源尺寸 32×31 和脑子自身位置，范围内的相邻行也可命中。已死亡、已压毁的脑子不再计分；魅惑小丑保持原来攻击僵尸的分支。
- 随机变身结果中的舞王（类型 8）、蹦极（类型 20）加入已有低血量保护集合：满血 65%、半血 25%、三分之一 4%、四分之一 3%、五分之一 3%。购买和召唤不额外抽取血量；车辆满血保护和僵王规则继续保留。

## 舞王错位原因与修复

实际 EXE 的 `SummonBackupDancer` 把伴舞出土时间设为 150 tick，而舞王召唤后的停留为 200 tick。原 `ZombieNotWalking` 对队友只检查啃食、冰冻和黄油，没有检查舞王的召唤停留阶段，所以伴舞出土后可能抢先移动。

随后 `UpdateZombieWalking` 又让每只僵尸分别从自己的 `_ground` 动画轨道取得位移。即使 `mVelX` 相同，也不能保证它们每次移动相同距离；不同动画阶段和逐只更新顺序会造成上下错位和后方伴舞追近。召唤接口还把舞王 X 转成整数，丢失了初始小数位置。

本版由舞王执行原生行走计算，再把本次真实位移分配给双向关联有效的伴舞；这些伴舞不再自行执行第二次行走。保留舞王原有动画速度、方向和全队停走／减速判定，不重新设定统一固定速度。新召唤保留舞王浮点 X，上下同 X，前后分别 -100、+100。

旧存档或补召唤后的现存偏差，在队伍行走时逐步恢复到上述队形，每次修正最多为当次位移的一半。队伍停止时修正也为零，避免瞬移；正常向左行走时不会为了归队向右倒退。成员的整数碰撞 X 同步更新。

队伍绑定复用原版 ID 的槽位和代际校验，并检查双向归属、类型、死亡阶段及魅惑状态。死亡／已复用槽位不会被当作队友移动，舞王消失后的独立伴舞回到原生行走，多队舞王各自管理。没有增加存档字段。
