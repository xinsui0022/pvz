# v3.0.2：清场奖励调整为 75 阳光

无尽「我是僵尸」吃完第五个脑子时，如果场上没有地刺、地刺王以外的存活在场植物，额外奖励由 100 改为 **75 阳光**，即掉落 3 枚可拾取的 25 阳光硬币。

仅调整清场奖励金额。每 3 关 +100、每 10 关 +500、奖励叠加、空场判定、每关只结算一次及存档记录均保持原规则。第 30 关清场时总奖励为 675 阳光（27 枚硬币）。其他功能包含 v3.0.1 的僵王修复，均保持不变。

安装工具支持从 v3.0.1 升级，并保留旧程序到 `backups/PlantsVsZombies.v3.0.1.exe`。

## 验证

2026-09-08 执行 `python -m unittest discover -s tests -v`，59 项测试全部通过。奖励回归覆盖清场 75 阳光、地刺和地刺王豁免、空场、残留植物、阶段奖励叠加、重复进入、存档记录和下一关结算。

与 v3.0.1 的 EXE 逐字节对比，仅文件偏移 `0x2df6a9` 的奖励立即数从 `0x64`（100）变为 `0x4b`（75），以及 PE 校验和的一个字节变化。指令 `0x7946a7` 为 `add edi, 75`，全部钩子地址与代码长度保持一致。
