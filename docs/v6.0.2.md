# V6.0.2：纸板植物与阵型均衡

2026-10-13。本地调整版本，等待用户实测，不提交或上传 GitHub。V6.0.1 的模式选择卡死修复继续保留。

## 玩法调整

- 挑战植物恢复传统“我是僵尸”的纸板绘制和静止待机。普通、升级植物及南瓜都沿用原生纸板处理，机枪、西瓜、冰瓜、忧郁等攻击逻辑保留。樱桃和辣椒等待时也不抖动。
- 每关寒冰蘑菇最多 2 株，统计包含尚未变身的模仿者目标。瞬杀特殊关也受此上限约束。
- 每关至少有 1 株磁力蘑菇。普通阵型以 1 株为基准；传统原本请求 2 株或 8 株磁力的阵型保留相应数量限制，不再把磁力槽位随机替换成炸弹。
- 普通攻击／辅助位置不再抽出樱桃、土豆雷、寒冰菇、毁灭菇、窝瓜或辣椒；原有瞬杀位置才有机会进行这些高级替代。普通关一次性威胁全场最多 3 株、每路最多 1 株，超限位置改为攻击植物。
- 传统“土豆雷／大嘴花”密集阵和无尽瞬杀阵保留集中瞬杀特色，可以放宽上述全场／单路数量限制；寒冰菇仍最多 2 株。杨桃阵保留杨桃位置，不变成炸弹混杂阵。
- 阳光蘑菇移出生成和模仿者目标池。普通向日葵位置、低概率双子向日葵和双倍阳光结算保留。
- 南瓜禁止覆盖樱桃、土豆雷、魅惑菇、寒冰菇、毁灭菇、窝瓜、辣椒，以及地刺／地刺王。模仿者按最终目标判断。大嘴花可以重复攻击，不属于这个一次性排除集合。

## 旧存档与生效时间

旧挑战存档加载后会恢复纸板待机，不重置植物血量、冷却、磁铁物件或正在进行的攻击状态。

**新阵型、数量上限、阳光菇排除和南瓜覆盖限制，在新开局或下一关生成时生效。** 已保存的当前阵型不会被强行重建，因此截图中原有的多炸弹或南瓜套毁灭菇布局可保留到该关结束。测试新布局时请重开挑战局，或完成当前关进入下一关。
