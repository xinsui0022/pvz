# V4.0.2 — 伴舞黄油修复、通关延迟与血量显示

- 修复原生黄油流程清除伴舞所属舞王关联的问题。黄油结束后仍属于原队伍；旧存档中舞王仍持有有效伴舞 ID 的断链也会恢复，不接管其他舞王的成员。
- 无尽我是僵尸消灭第五个脑子时，只要存在存活僵王或存活在场向日葵，就提供 2000 个逻辑帧（正常速度 20 秒）的操作时间。修正此前要求两者同时存在的条件。暂停不计时，剩余时间随存档保存；触发后不会因目标死亡提前结束，也不会重复延长。
- 我是僵尸中按 **F8** 开关僵尸血量显示，默认关闭，暂停时也可切换。显示身体、头盔、盾牌的合计剩余血量及血条；开关状态跨关并随存档保存。显示只读取血量，不修改伤害或生命值。
- 随机生成四人雪橇队时，整队同步到生成位置，避免仅队长位置改变。每队抽取前方 4 或 5 格的虚拟冰道，各占 50%；记录原点与距离，读档不会重抽。不会写入地图冰道，超出虚拟距离后使用原生无冰损伤流程；已有真实冰道仍可延长滑行。
- 包含 V4.0.1 的低血量权重扩展、僵王降至 1 血时的原生破损与烟雾修复。
