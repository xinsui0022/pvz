# V6.0.0：挑战性我是僵尸模式

2026-10-13。传统模式保留当前已验证的纸板植物玩法；新增挑战模式，共用现有随机变身、卡组与价格、暂停预约、阶段奖励、僵王和换关修复。

## 使用

从原游戏入口或 Steam 启动，进入解谜页面，点击任意“我是僵尸”关卡。游戏内弹出“传统模式”和“挑战模式”两个按钮。选择对应规则继续其存档，或按原来的继续／重开流程开始新局。

挑战新局开局 **3500 阳光**；传统新局保持 150。读档和无尽换关不重置余额。模式在整局固定，随存档和换关保留。模式切换通过返回解谜页面再选择完成。

## 植物与触发

- 排除墓碑吞噬者、睡莲、缠绕海藻、海蘑菇、路灯花、三叶草、花盆、咖啡豆、金盏花、香蒲、吸金磁、玉米加农炮。
- 其余普通植物、升级植物和模仿者均有机会出现。模仿者只变为允许的真实植物。
- 保留传统阵型的植物数量、行列和空格限制。在符合的种类中，70% 先按同功能加权选择，30% 从全局池选择。高级植物权重较高：例如同类坚果中高坚果 14/16，投手中西瓜及冰瓜 22/24，豌豆中机枪 14/25。
- 全局池仍覆盖允许的弱植物，因此不是每一格都固定生成高级植物。
- 原阵型向日葵位置保持普通向日葵，维持原经济来源；其他随机位置才可能出现双子向日葵。双子在全局池权重为 3/221，约 1.36%，同类偏好分支不会提升此概率。
- 双子向日葵的啃食、豌豆／机枪／投篮伤害及原有摧毁结算掉落双倍阳光。例如 300 血整株摧毁，普通向日葵 8 枚、双子 16 枚 25 阳光硬币。其他阶段奖励不翻倍，仍不自动生产阳光。
- 南瓜以 20% 概率覆盖可容纳它的植物，作为额外护甲层；地刺和地刺王不套南瓜。

挑战植物使用原生动画、武器和升级植物初始化。蘑菇在白天保持清醒，土豆雷已武装。樱桃和辣椒在等待时保持可见的原生静止动画。

| 植物 | 条件 |
| --- | --- |
| 樱桃炸弹 | 原版 115 像素爆炸范围、相邻行规则内至少 1 只可被爆炸伤害的敌方僵尸。 |
| 火爆辣椒 | 同行至少 1 只可被爆炸伤害的敌方僵尸。 |
| 毁灭蘑菇 | 原版 250 像素范围、跨行规则内至少 3 只可被爆炸伤害的敌方僵尸；或者被啃食至死亡。 |
| 寒冰蘑菇 | 全图至少 3 只存活的敌方僵尸；或者被啃食至死亡。 |

死亡、正在死亡、魅惑僵尸和僵王冰火球不计入触发数量。毁灭菇保留原版爆炸及当前关弹坑；下一关沿用原版清理所有网格物件的流程，弹坑恢复为可生成植物的地面。范围判断直接调用原版矩形／圆形碰撞，效果调用原版爆炸、同行烧毁或全图冰冻。

## 存档和备份

传统关卡沿用 `game<玩家ID>_61.dat` 至 `_70.dat`。挑战关卡使用同一玩家的 `_161.dat` 至 `_170.dat`，但运行时游戏模式编号仍为 61–70，所以继续共用原有修复。进行中规则标记使用“我是僵尸”闲置、原生序列化的 `Challenge +0xB4`，与蹦极价格、救援、预约和僵王状态分开。

开发前传统版已验证、上传 GitHub：提交 `964c8bb5815ee22e68972aeca2bbb069ab65da1e`，标签 `traditional-stable-2026-10-13`。

本机完整备份在 `backups/traditional-stable-20261013/`，包含游戏运行文件、原始 EXE、源码 ZIP、Git bundle、当前 `userdata` 和逐文件 SHA-256 清单。传统 EXE 的 SHA-256 为：

```text
3a43abb5464860f25dbfab7f6850e555bcb3a9939633d28bf36098b1f967c01c
```

如需还原传统程序，关闭游戏后，将上述备份 `game/PlantsVsZombies.exe` 复制回游戏根目录。通常不必回退玩家存档；备份中的 `userdata` 仅在确实需要回退进度时使用。原版删除玩家的流程不会清理新的挑战存档文件，但不影响日常继续或切换。

可以独立重建完全一致的传统程序，不改当前挑战补丁包：

```powershell
python tools/build_patch.py --traditional --output backups/PlantsVsZombies.traditional-rebuilt.exe --package-dir backups/traditional-rebuilt-patch
```

仓库继续只分发补丁源码、差分包、测试与文档。完整游戏、资源、存档和本机备份不进入 GitHub。
