# V6.0.3：挑战僵尸与双子阳光

2026-10-14。本地测试版本，不提交或上传 GitHub。V6.0.1 的选择入口修复和 V6.0.2 的纸板植物、阵型均衡继续保留。

## 挑战模式调整

- 随机路障僵尸的问号帽子当前／最大血量为 **640**，即原路障帽子 370 加身体 270。身体仍为原生 270。**帽子掉落立即随机变身**，包括磁力菇摘帽；没有延后到身体死亡，没有修改原变身入口或身体死亡代码。F8 显示身体与护具合计，因此刚生成时合计为 910。
- 随机变身结果的身体、帽子和盾牌均使用对应种类的满血值，取消挑战模式的低血量随机结果。初始化后仍正常受伤，不逐帧补血。
- 挑战小鬼身体当前／最大血量为 **270**，与普通僵尸相同。
- 挑战僵王身体当前／最大血量为 **2000**，覆盖原生初始化和随机变身中另外一处 500 血赋值。原有的下头未受伤惩罚规则继续保留。
- 冰车产生的真实地图冰道在当关持续存在，进入下一关并开始游玩 **2 秒（200 个逻辑帧）** 后消失；暂停和关卡介绍不计时，存档保留剩余时间。下一关生成植物时临时隐藏继承冰道，再恢复冰道，避免植物位置被冰道挡住。辣椒不会提前清除挑战冰道；私人雪橇滑行仍不生成地图冰道。
- 挑战所有普通向日葵生成位置均改为真正的 **双子向日葵**，包括原生固定槽位和模仿者目标。使用双子资源和纸板绘制，**血量保持 300**，按实际损失血量结算两倍阳光，完整一株共 **400**。啃食、投射伤害、爆炸混合结算不重复，完整啃食共掉落 16 枚 25 阳光硬币。原本的普通／双子随机权重合并为双子，保持收入位置数量；不额外自动产阳光。
- 无尽关卡完成脑子后，有存活双子向日葵时仍保留原有 20 秒可操作的补吃时间。

传统模式保留问号帽子 370、原随机血量规则、小鬼 70、僵王 500、原冰道时长和普通向日葵 200 阳光。所有新玩法均检查挑战标记和我是僵尸关卡范围。

## 生效与备份

重新启动游戏后，新生成的僵尸采用新血量，新开局或下一关生成的向日葵全部为双子。已保存的当前植物、僵尸不会被重建或恢复血量；旧挑战存档中的活跃地图冰道会按新规则保留。测试整套新规则时可重新开挑战局。
