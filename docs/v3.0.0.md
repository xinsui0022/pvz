# 第三个大版本 v3.0.0

本版只把新增行为限制在「我是僵尸」系列关卡（游戏模式 61–70）。

## 本版内容

- 奖励阳光改为掉落可拾取的 25 阳光硬币。每 3 关奖励 100，每 10 关奖励 500，清除除地刺和地刺王外的全部植物奖励 100；同一关可叠加，完成一次脑子阶段只结算一次。
- 普通、旗帜、铁栅门、气球、海豚、潜水、小鬼、伴舞、报纸、矿工、跳跳以及豌豆头、机枪头、窝瓜头继续使用低血量权重：满血 65%、半血 25%、三分之一 4%、四分之一 3%、五分之一 3%。随机投篮和冰车固定满血，避免特殊僵尸刚生成就自爆。
- 随机蹦极保留初始化时选择的完整目标，跳过后续把旧路障 X 坐标覆盖到蹦极身上的代码，统一标记和落点。
- 冰车留下的冰道从 3000 个逻辑更新延长到 4500 个；原游戏每次更新 10 毫秒，因此增加 15 秒。
- 窝瓜头先播放跳起和下压动画，落下命中时压瘪脑子，只计分一次；跳跃落点对准脑子。雪人不再进入回头逃跑阶段，旧存档中已回头的雪人也恢复前进。
- 僵王在本模式初始化固定 500 点生命。每次下头记录开始血量；若未受伤，在原定抬头前 50 个逻辑更新（0.5 秒）将剩余血量降到 1，随后进入原版的 1 血死亡流程。已经受伤的僵王不触发本规则，各僵王分别记录。
- 空格暂停和恢复；暂停时不创建读报僵尸模态窗口，保留选卡及落点预览。预约正常扣费，恢复后按顺序调用原版放置流程，不重复扣费；最多 27 个预约，队列满时不扣费、不切换蹦极价格。预约保存在关卡数据中，支持存档；切出窗口只暂停，不触发恢复。

## 失败 V3 的修正

旧 V3 在 `0x4599e0` 错误拦截了 `MessageWidget::Draw`，把 ECX 当作提示对象指针。实际对象从栈传入，崩溃日志中 ECX 为代码地址 `0x61fcf3`，在 `0x794b12` 发生非法访问。本版保持该绘制函数原样，在真正的 `LawnApp::DoPauseDialog` 入口处理暂停。

同时修正旧 V3 在 `0x5353cf` 覆盖 7 字节、破坏下一条动画调用的问题：原指令只有 6 字节，续接位置必须是 `0x5353d5`。脑子压毁入口需要 EAX 传递脑子指针；旧测试未校验该参数，本版执行实际压脑指令和计分入口检查。

## 暂停项目调查

查询了 [PvZRNoBackgroundPause](https://github.com/RaptorRush135/PvZRNoBackgroundPause) 和经典版工具 [AsmVsZombies](https://github.com/vector-wlc/AsmVsZombies)。前者针对 Replanted 且用于禁止后台暂停；后者的通用接口不直接提供本修改版要求的模式限制及预约流程。本版将所需功能集成到版本锁定的补丁中，不额外安装 DLL 或修改器。

预约复用 Challenge 中本模式闲置的消消乐字段：`+0x10` 标记、`+0x0c` 数量、`+0x14..+0x49` 的 54 字节存放 27 条类型／列／行记录。它们随原版关卡保存；不改变奖励记录、蹦极交替价格或其他模式的数据结构。

## 验证

2026-09-07：`python -m unittest discover -s tests -v` 的 52 项测试全部通过。测试执行实际 x86 补丁指令，外部图形、声音和硬币分配入口使用 ABI 桩验证。覆盖旧 V3 崩溃复现、全部续接指令边界、模式边界、原版选卡判定、真实预约扣费与生成流程、存档队列、冰道时长、窝瓜压脑及僵王计时。

已安装到本地游戏并实际启动：主菜单正常，「我是僵尸」无尽关卡正常绘制。暂停时没有读报窗口；选路障卡并预约后，阳光从 150 变为 75，僵尸数保持 0，预约数变为 1；空格恢复后僵尸数变为 1，预约清空，阳光仍为 75。已截屏核对生成位置，并再次暂停关卡。

本轮没有穷举所有随机僵尸动画、地图及长时间多僵王换关组合，这些仍需完整试玩。V2 程序保留在 `backups/PlantsVsZombies.v2.0.0.exe`，失败版本保留在 `backups/PlantsVsZombies.v3-failed.exe`，测试前存档备份在 `backups/userdata-before-v3-repair/`；上述本地备份不上传。
