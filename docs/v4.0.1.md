# V4.0.1 — 换关补吃时间与僵王受伤表现

## 行为

- 无尽我是僵尸（模式 70）消灭第五个脑子时，同时有存活在场向日葵和存活僵王，获得 2000 个逻辑帧（正常速度 20 秒）的操作时间。条件仅在完成时检查一次，不会因之后向日葵或僵王死亡提前结束，也不会重复触发延长。
- 期间保留正常操作，不设置原生关卡结束标志；暂停停止游戏逻辑时，倒计时也停止。剩余时间随存档保存。僵王死亡、场上无僵尸且阳光不足，也不会把已经吃完脑子的胜利判成失败。
- 到时接入原生完成流程；该流程设置换关计时器时，用 1 帧代替原本额外的 500 帧。原生钱包奖励流程保留。其他我是僵尸关卡没有无尽下一轮，不增加延迟。
- 周期阳光与清场奖励仍在吃完第五个脑子时判断、发放一次；补吃期间清掉向日葵不会补发清场奖励。
- 小丑（15）和高坚果头（31）此前走原修改版的五档等概率血量抽取，现在加入满血 65%、半血 25%、三分之一 4%、四分之一 3%、五分之一 3% 的集合。只影响路障死亡随机变身，不改变购买或其他召唤来源。
- 僵王一次下头未受伤，抬头前 0.5 秒降至 1 血时，改用原生身体伤害流程处理 `当前血量 - 1`。同步更新头、下巴、手、拇指、脚的破损贴图，以及跨越低血量阈值时的烟雾、粒子和声音。随后恢复特殊存活标记，仍需后续真正受到伤害才死亡。

## 投石车检查结论

这是原游戏机制，未修改：投石车和冰车低于 **200 血**，每逻辑帧有 **1/5** 概率自然掉血；最大血量至少 500 时每次掉 3，否则掉 1。掉至零进入死亡爆炸；地刺伤害也可直接触发车辆死亡。

投石车冒烟阈值是身体血量低于最大血量的三分之一。通常最大血量为 850，所以会先在约 283 血以下冒烟，到 200 血以下才出现上述自然衰减。冒烟不是立即自爆开关。随机变身的投石车和冰车继续固定满血。

已对照本地 EXE 的 `0x52B4D0–0x52B551`（车辆自然衰减）、`0x531488–0x531525`（投石车伤害与死亡）、`0x52D710`（破损阶段）和参考重建源码。
