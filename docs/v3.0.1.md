# v3.0.1：僵王保留 1 血

修正「我是僵尸」中僵王第一次无伤下头后直接死亡的问题。抬头前 0.5 秒的惩罚只将血量降到 1，僵王继续抬头、待机、再次下头；之后受到实际伤害仍正常死亡。其他模式保留原版规则。

## 原因

原版 `TakeBodyDamage` 会将僵王受到致命伤后的血量钳制为 1，供 `UpdateBoss` 的三个阶段识别死亡：待机、吐球前、吐球后。初始 V3 直接写入 1 血，没有区分惩罚与致命伤，因此同一次更新就进入死亡流程。旧测试只检查血量，没有执行后续死亡分支。

## 修复

- 在僵王原有、随存档保存的下头记录字段中，标记「因无伤惩罚而保留 1 血」。
- 三处死亡检查识别此标记，让它完成抬头及后续行动；再次下头不会丢失标记。
- 实际正数身体伤害清除标记，保留原版致命伤钳制和死亡流程。零伤害不清除，多个僵王独立记录。
- 安装工具支持从初始 V3 升级，并备份到 `backups/PlantsVsZombies.v3.0.0.exe`。

2026-09-07 执行 `python -m unittest discover -s tests -v`，59 项测试全部通过；差分补丁完整性检查通过。
