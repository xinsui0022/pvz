# V4.0.3 — 换关条件、阳光与雪橇修复

2026-09-12，小版本更新，仅做本地 Git 提交。

- 无尽我是僵尸吃完第五个脑子后，向日葵仍触发 20 秒游戏时间等待。僵王改为等待其在吃完脑子后新放出的冰车完整铺满一整道；已有冰道、购买或随机变出的冰车、上一关的记录均不算。冰车中途被地刺破坏而未铺满时继续等下一辆。两种条件同时存在时须都满足。暂停不计时，进度随存档保留。若僵王和已放出的有效冰车全部死亡，则解除僵王等待，避免已获胜的关卡卡死。
- 清完地刺、地刺王以外的全部植物，奖励由 75 改为 100 阳光，仍在吃完脑子时结算一次、掉落四个可拾取的 25 阳光。每 3 关 +100、每 10 关 +500 不变，第 30 关满足清场条件时合计 +700。
- 购买蹦极的价格改为 75 → 125 → 75 → 125 循环。显示、余额检查、扣费和暂停预约使用同一价格；取消及失败不切换。
- 我是僵尸首次余额 ≤25 时，余额增加 5000；在画面底部通过原生游戏提示显示「触发恢复机制，恢复5000阳光，最后一次恢复」。每局只有一次，跨关、读档不会重置，重新开局恢复机会。使用游戏提示栏，不弹出对话框。
- 随机变出的雪橇队，第一只留在变身位置，后三只从地图右侧依次滑入，接近后才开始整队滑行。队长从变身位置最多滑 320 像素（4 格），红线为更早的停止边界；已有真实冰道不再延长距离。已经在红线左侧变身的队长不会被传送回右侧；后三只也有独立的 4 格到达上限。停止滑行时解除雪橇护甲并进入原生散队流程，随后普通步行、受伤照常。
- 舞王增加秒杀植物的距离上限：大嘴花和土豆雷索敌、窝瓜起跳前重新索敌及落地伤害都检查舞王与植物原种植列的距离，不能隔两格击杀。窝瓜移动后的坐标不能扩大原种植列的作用范围。近距离伤害、伴舞及其他游戏模式保持原规则。
