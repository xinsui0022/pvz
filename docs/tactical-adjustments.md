# 矿工后方保护与蹦极交替价格

## 矿工

在 Plant::FindTargetZombie 的大嘴花专用分支 `0x4676ea` 增加排除条件：I, Zombie、植物列为 0、僵尸类型 17、矿工阶段 32..38、僵尸 mX <= 植物 mX+40。此坐标界限覆盖矿工刚出土及从背后接触最左植物的过程，不提供全场永久免疫。完整回放被覆盖的 MOV/CMP，并保持寄存器和调用栈。

UpdateChomper 在开始咬合和实际吞噬时都会再次调用 FindTargetZombie，因此即使它已开始咬合，矿工出土也不会被该次咬合吞掉。针对性测试运行完整目标选择函数，重现原程序返回矿工作为目标，确认补丁排除，同时保持其他列、其他种类、离开后方范围和非 I, Zombie 模式原有规则。

## 蹦极

`Plant::GetCost` 入口 `0x467b00` 对种子 66、模式 61..70 返回 75 或 100；该函数同时服务卡片文字与 Board::GetCurrentPlantCost。其他种子、其他模式和无 Board 的界面继续执行原实现。

Challenge+0xb8 原为智慧树对话索引，在 I, Zombie 未使用。最低位为价格状态，0=75、1=100。Challenge 构造函数原生清零，保存文件原生序列化整个结构，换关不重置。与奖励所用 +0x70 独立。旧版 I, Zombie 存档该值为 0，初次启用从 75 开始。

仅在鼠标购买路径 `0x42a42a`，IZombiePlaceZombie 成功返回后翻转状态。非法落点、取消、扣款失败都不会到达此处；随机变身调用 AddZombieInRow 而不会到达此处。原游戏自带免费放置作弊若启用，成功放置仍会交替。

测试实际 GetCost/GetCurrentPlantCost、实际扣款分支及成功/失败控制流，复制整个 Challenge 模拟序列化恢复，并执行实际构造函数初始化验证新局恢复 75。游戏内动画和鼠标交互尚需用户试玩确认。
