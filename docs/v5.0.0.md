# V5.0.0 — 单僵王、兜底时机与音乐恢复

## 玩法

- **兜底**：同时满足阳光余额 ≤25、场上无存活僵尸，且本局未使用兜底，才增加 5000 阳光。死亡及死亡动画中的僵尸不阻止触发。恢复先于原生失败判定，因此这次不会因为低阳光而失败。无尽换关、存档读档不重置次数，重新开局重置；已经用过后仍按正常失败规则处理。
- **最多一个僵王**：已有存活僵王时，再次抽中僵王会改出一个非僵王，同时保留一次延后的僵王机会。当前僵王死亡或离场后，接下来最多 5 次路障死亡随机变身内必出僵王；自然提前抽中也会兑现。场上仍有僵王期间不会消耗或重置倒计数。反复抽中不叠加多个欠额，保留一次补出机会。
- **旧存档兼容**：若读入的场面已有多个僵王，保留第一只存活僵王，清理额外僵王并保留一次补出机会，不清理其他僵尸。延后次数随存档及关卡进度保存。
- **僵王音乐**：僵王出现时读取游戏音乐对象当前的曲目，保存后切换为最终僵王关的《Brainiac Maniac》。僵王死亡、离场或进入下一关时恢复保存的曲目；先前无音乐则恢复无音乐。不会根据我是僵尸模式硬编码恢复曲目。支持修改器通过游戏切歌接口选用的曲目；不承诺恢复外部播放器或绕开游戏音乐对象的音频替换。恢复曲目时从该曲目开头播放。
- **等待提示和提速**：吃完脑子进入僵王铺冰等待时，下方原生游戏提示显示「正在等待冰车僵尸」，等待期间持续刷新。该阶段僵王的普通召唤固定选择冰车，第一辆车的召唤冷却缩短至最多 50 个逻辑帧；既有动作和动画自然结束，不强行中断。存在有效冰车正在铺道时不继续催促召唤；冰车中途损毁后再催促下一辆。
- **完整铺道条件不变**：必须是吃完脑子后由僵王新放出的冰车，且该车真正铺至整条道最左端。旧冰道、其他来源的冰车、上一关记录不算；遇到地刺而未铺满继续等待。向日葵的 20 秒等待不变。若僵王与所有有效冰车都已死亡，保留防卡关处理。

其余 V4.0.3 的玩法与修复保留，包括清场 +100、蹦极 75/125 循环、雪橇从右侧入场及红线限制、舞王秒杀植物距离修复和 F8 血量显示。

## 技术与验证范围

随机选择保留没有僵王和补出机会时的原始 35 张票分布（僵王 3/35）。重复抽中的替代结果在其余 32 种类型中均匀选择。只在随机变身时消耗补出次数，购买、伴舞召唤等不计入五次。

新状态使用 Challenge 中我是僵尸未使用的六个云动画字段 `+0x78..+0x8C`；原生构造初始化为零，整个 Challenge 随存档序列化。首次加载旧存档时用版本标记初始化。音乐、提示等引擎调用前后保存寄存器、栈和浮点状态。

自动化执行实际 x86 指令，覆盖原生失败判断、音乐切换 ABI、单僵王和五次补出、旧存档多僵王处理、原曲与静音恢复、换关及读档、提示刷新及清除、冰车优先与模式边界。音频设备、渲染和部分引擎分配使用测试桩；本轮没有游戏内实玩，不把测试通过等同于听觉或画面验收。
