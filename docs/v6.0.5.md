# V6.0.5：挑战稳定版

2026-10-14。用户确认此前纸板、阵型、僵尸增强、双子阳光以及开局／蹦极调整均没有明显问题，要求完成博士调整后建立完整备份并提交 GitHub。

## 本次博士调整

- 挑战随机变身生成的博士以 **50%／50%** 概率使用 **10000／5000** 当前血量，最大血量均为 10000。只在生成时抽签一次，保持身体受伤阶段与血条含义一致。
- 挑战模式取消下头未受伤时降到 1 血的惩罚。博士仍正常抬头、继续行动，实际受到致命伤害时正常死亡；旧惩罚标记不再使挑战博士停留在 1 血而免死。
- 传统博士继续为 500 血，保留下头未受伤降到 1 血及随后受伤才死亡的规则。
- 新血量只影响更新后新生成的博士，已有存档中的博士不自动恢复或增加血量。取消挑战惩罚的规则在旧存档中也生效。

## 本次稳定备份收录的既有修复

- 模式选择后的卡死修复；传统／挑战存档分别保存。
- 挑战植物采用纸板外观，普通关以攻击植物为主，限制一次性威胁全场最多 3 株、每路最多 1 株；传统瞬杀特殊阵和杨桃阵保留特色。
- 寒冰菇最多 2 株，每关确保磁力菇，排除阳光菇，南瓜不覆盖一次性植物。
- 问号帽子 640 血、身体仍为 270，掉帽立即变身；其他普通随机结果满血，小鬼 270 血。
- 挑战冰道当关持续，下一关开始游玩 2 秒后消失，不阻挡新关植物生成。
- 挑战普通向日葵生成位置全部改为双子，仍为 300 血，完整一株按伤害结算 400 阳光。
- 挑战新开局 150 阳光，蹦极固定 125，显示、购买判断和扣款一致；传统蹦极保留 75／125 交替。

历史说明见 [V6.0.1](v6.0.1.md)、[V6.0.2](v6.0.2.md)、[V6.0.3](v6.0.3.md) 和 [V6.0.4](v6.0.4.md)，当前博士规则以本版为准。
