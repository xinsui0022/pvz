# v3.0.3：暂停连续预约与舞王吞咬距离

这两项修复仅作用于「我是僵尸」系列（模式 61–70）。

- 暂停时，成功付费预约后立即完成该卡原本为零时长的刷新，可以再次选择同一张卡。保留使用次数统计、阳光扣费、蹦极 75/100 交替及 27 个预约上限。未暂停和其他模式沿用原刷新流程。
- 大嘴花原本在吞咬中或目标正在啃食时额外扩大 60 像素的选敌距离。伴舞死亡后，这会让吞咬动作重新选到正常距离以外的舞王。舞王现在必须进入正常吞咬距离才能被选中；不赋予舞王无敌，也不改变伴舞和其他僵尸的判定。

验证使用 Unicorn 执行实际补丁机器码：覆盖连续三次购买同卡、扣费和预约数量、蹦极交替、原版卡片使用流程、后续可选状态、其他模式，以及实际矩形重叠计算下的舞王远近目标判定。完整图形游戏中的土豆雷／窝瓜组合仍需实玩确认。

安装会自动备份现用 v3.0.2 为 `backups/PlantsVsZombies.v3.0.2.exe`。
