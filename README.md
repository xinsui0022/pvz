# 我是僵尸：随机僵尸补丁修复

当前版本：**v4.0.2**。修复伴舞中黄油后脱队；无尽我是僵尸吃完脑子时，只要仍有存活僵王或向日葵，就等待 20 秒游戏时间再通关；新增 **F8** 一键开关僵尸血量显示；四人雪橇队随机获得前方 4 或 5 格的虚拟冰道，各占 50%。详见 [V4.0.2 更新说明](docs/v4.0.2.md)。包含 [V4.0.1 修复](docs/v4.0.1.md)和此前的 [V4 功能](docs/v4.0.0.md)。

后续方向见 [Plus 规划与开发交接](docs/plus-plan.md)（仅规划，尚未开发）。

针对用户提供的「叔基丁路障随机变身版」PvZ **1.0.0.1051** 制作的二进制差分补丁。保留原来的路障死亡随机变身机制。仓库只提供补丁、可审查的 x86 汇编源码、安装工具及测试，不分发完整游戏或存档。

## 安装与还原

关闭游戏，把仓库中的文件放进该修改版游戏目录。有 Python 3 即可安装，不需要安装分析依赖：

```powershell
python tools/patch_game.py --check
python tools/patch_game.py
```

工具校验整个 EXE 的 SHA-256，拒绝修改其他版本；支持从 V2 及已识别的旧补丁升级。原始版本备份在 `backups/PlantsVsZombies.original.exe`，V2 备份在 `backups/PlantsVsZombies.v2.0.0.exe`，失败的 V3 备份在 `backups/PlantsVsZombies.v3-failed.exe`，Steam 原配置在 `backups/steam-partner/`。

恢复到用户最初提供的修改版程序与 Steam 配置：

```powershell
python tools/patch_game.py --restore
```

此处“原始版本”指修复前的随机变身修改版，并不是 Steam 官方原版。Steam 验证游戏完整性可能覆盖修改后的 EXE、配置或资源。

## 验证与当前限制

2026-09-07 战术调整：“我是僵尸”购买蹦极按 75 → 100 → 75 → 100 循环。卡片显示、可购买判定和实际扣款使用同一价格；成功放置后切换，取消或阳光不足不会切换，随机生成不计次数。状态跨关并随存档保留，重新开局恢复 75。旧存档第一次使用本补丁从 75 开始。

最左列大嘴花不再吞掉从后方出土的矿工：保护覆盖钻地、出土、眩晕和刚转身行走，直到矿工走过该植物中心附近。开始咬合和完成咬合均应用检查；其他列和普通僵尸仍按原规则。

2026-09-08：清场奖励由 100 调整为 75。无尽“我是僵尸”吃完第五个脑子时结算：每 3 关 +100、每 10 关 +500，两档可叠加；如果场上没有地刺、地刺王以外的存活在场植物，再 +75（空场也满足）。每关只结算一次，记录随存档保存。第 30 关满足清场条件时总共 +675。原来的钱包奖励保留。

低血量权重保持 V2 的满血 65%、半血 25%、三分之一 4%、四分之一 3%、五分之一 3%。适用于随机生成的普通、旗帜、报纸、铁栅门、伴舞、普通鸭子救生圈、潜水、海豚、气球、矿工、跳跳、小鬼，V3 新增的豌豆头、机枪头、窝瓜头，V4 新增的蹦极、舞王，以及 V4.0.1 新增的小丑、高坚果头。随机冰车和投篮固定满血，其他种类保持原规则。此处仅影响随机变身，购买卡片和舞王召唤伴舞不会额外抽血量。

第三个大版本还将奖励从余额直加改成多个 25 阳光硬币掉落；每 3 关和每 10 关奖励仍可叠加，清场奖励只在完成脑子阶段时结算一次。投篮、冰车变身为随机僵尸时保持满血，避免低血量特殊僵尸立即自爆。

「我是僵尸」中按空格暂停或恢复。暂停时不创建读报僵尸窗口，鼠标仍可选卡和预约放置；预约时按正常价格扣费，恢复后按顺序生成，不重复扣费。一轮暂停最多预约 27 只，满额或余额不足不会扣费或切换蹦极价格。预约随关卡存档保存；切出窗口只会暂停，不会意外恢复。其他模式保留原暂停窗口和操作限制。

每个僵王的绘制部件现在绑定自身。无尽模式里，后续僵王在绘制时呈蓝色并向左错开，冰火球仍显示在实际位置；绘制结束立即恢复临时状态，不会使僵王真的减速。双僵王的实际画面仍需游戏内确认。

自动化测试执行真正的 x86 补丁指令，已覆盖原崩溃复现、修复后的栈与寄存器、浮点状态、伤害边界、奖励硬币数量、模式限制、水生状态切换、脑子单次计分、精确随机权重、车辆满血、蹦极目标、暂停放置及补丁逐字节还原。渲染、声音及部分引擎调用由测试桩模拟。

自动化验证和游戏内检查分别记录在 [V3 版本说明](docs/v3.0.0.md)。测试通过不代表已验证所有动画、地图或长时间无尽换关组合。特别需要检查水生僵尸的跳跃／潜水视觉效果与多个僵王同时在场的换关情况。完整实测清单见 [docs/validation.md](docs/validation.md)。

## 开发与重建

```powershell
python -m pip install --target .tools -r requirements.txt
python tools/build_patch.py
python -m unittest discover -s tests -v
```

重建读取本地备份 EXE，输出候选程序到 `backups/PlantsVsZombies.patched.exe`，并生成 `patches/izombie-fixes.json` 与地址清单。候选程序不会自动替换游戏。输入散列与输出散列见 [patches/manifest.json](patches/manifest.json)。

技术原因与 ABI 说明见 [docs/analysis.md](docs/analysis.md)。参考函数来自 [PlantsVsZombies-decompilation](https://github.com/ruslan831/PlantsVsZombies-decompilation) 并逐项对照本地可执行文件；参考项目仅用于阅读，没有编译或上传其内容。
